# Sequential engineering

One Build parent implements one task in one ordinary Git branch. No worker agents, parallel implementation or task graph. For complex work identify relevant dependencies and implement sequentially. Optional read-only architect (Luna High) or one Sol Medium advisor only for genuinely difficult decisions; one consultation at a time, no nested delegation. Parent owns native commands and delivery. Independent reviewer verifies exact candidate/evidence. Fix confirmed defects; one bounded adjudication for disputed findings. Never merge automatically.
