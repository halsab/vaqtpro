# Sequential engineering

One Build parent implements one active task at a time, each in its own ordinary Git branch. The same conversation can continue with a fresh task after verified delivery. No worker agents, parallel implementation or task graph. For complex work compare viable designs at the type/API boundary, identify affected consumers and invariants, choose the smallest coherent change, and implement independently verifiable slices sequentially. Optional read-only architect (Luna High) or one Sol Medium advisor only for genuinely difficult decisions; one consultation at a time, no nested delegation. Parent owns native commands and delivery. Independent reviewer verifies exact candidate/evidence. Fix confirmed defects; one bounded adjudication for disputed findings. Never merge automatically.
