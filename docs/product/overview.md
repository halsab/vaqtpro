# Vaqtpro

Vaqtpro — приложение, которое помогает узнавать времена намаза и пользоваться
другими полезными функциями, связанными с намазом.

## Цель

Давать пользователю удобный доступ к информации о временах намаза и
сопутствующим возможностям в одном приложении.

## Основные возможности

- Просмотр времён намаза.
- Дополнительные функции, связанные с намазом.
